# 🎙️ מערכת תמלול שידור חי בזמן אמת

מערכת מתקדמת לתמלול אוטומטי של שידורים חיים בעברית, עם תמיכה מיוחדת לכאן 11 ושידורים נוספים.

## ✨ תכונות עיקריות

- **תמלול בזמן אמת** - תמלול מיידי של שידורים חיים
- **טיפול חכם בשגיאות** - התאוששות אוטומטית מתקלות רשת ושגיאות
- **ממשק משתמש אינטואיטיבי** - ממשק web נוח בעברית
- **תמיכה בכאן 11** - תמיכה מובנית בשידור כאן 11
- **שידורים מותאמים אישית** - תמיכה בכל שידור HLS/m3u8
- **ייצוא תמלול** - שמירה לקובץ טקסט
- **מעקב עלויות** - מעקב בזמן אמת אחר עלויות API
- **סטטיסטיקות** - מידע על ביצועים ושגיאות

## 🚀 התקנה מהירה

### דרישות מקדימות

1. **Python 3.8+**
2. **ffmpeg** - לעיבוד אודיו:
   ```bash
   # Ubuntu/Debian
   sudo apt-get update && sudo apt-get install -y ffmpeg

   # macOS
   brew install ffmpeg

   # Windows
   choco install ffmpeg
   ```
3. **OpenAI API Key** - [קבל כאן](https://platform.openai.com/api-keys)

### שלבי התקנה

1. **שכפל את הפרויקט**:
   ```bash
   git clone <repository-url>
   cd live_transciber
   ```

2. **התקן תלויות Python**:
   ```bash
   pip install -r requirements.txt
   ```

3. **הגדר משתני סביבה**:
   ```bash
   cp .env.example .env
   ```

   ערוך את קובץ `.env` והוסף את מפתח ה-API שלך:
   ```
   OPENAI_API_KEY=sk-your-key-here
   ```

4. **הפעל את המערכת**:
   ```bash
   python app.py
   ```

5. **פתח בדפדפן**:
   ```
   http://localhost:7860
   ```

## 📖 הוראות שימוש

### תמלול שידור כאן 11 (ברירת מחדל)

1. וודא שהתיבה "כאן 11" מסומנת ✅
2. לחץ על "התחל תמלול" ▶️
3. המתן מספר שניות עד שהתמלול יתחיל להופיע
4. התמלול יתעדכן בזמן אמת בחלון הראשי

### תמלול שידור אחר

1. בטל את הסימון מ"כאן 11"
2. הדבק את ה-URL של השידור (חייב להיות HLS/m3u8)
3. לחץ על "התחל תמלול" ▶️

### הגדרות מתקדמות

לחץ על "הגדרות מתקדמות" כדי לשנות:
- **משך צ'אנק**: משך כל קטע אודיו לתמלול (5-30 שניות)
  - ערך נמוך = עדכונים מהירים יותר, עלות גבוהה יותר
  - ערך גבוה = עלות נמוכה יותר, עיכוב גדול יותר

### ייצוא תמלול

1. לחץ על כפתור "ייצא" 💾
2. הקובץ יורד אוטומטית עם חותמת זמן
3. ניתן גם להעתיק ישירות מהחלון עם כפתור ההעתקה

## ⚙️ קונפיגורציה

### משתני סביבה (.env)

```bash
# חובה
OPENAI_API_KEY=sk-...

# אופציונלי (יש ברירות מחדל)
CHUNK_DURATION=10           # משך צ'אנק בשניות
AUDIO_SAMPLE_RATE=16000     # קצב דגימה
AUDIO_CHANNELS=1            # מספר ערוצי אודיו
AUDIO_BITRATE=32k           # קצב סיביות
```

### התאמה אישית של הגדרות

ערוך את `config.py` לשינוי:
- מגבלות retry
- timeouts
- הגדרות Whisper
- הגדרות UI

## 🔧 פתרון בעיות

### "ffmpeg not found"
```bash
# וודא שffmpeg מותקן:
ffmpeg -version

# אם לא, התקן לפי ההוראות למעלה
```

### "OPENAI_API_KEY is missing"
```bash
# וודא שיש קובץ .env עם המפתח:
cat .env

# או הגדר משתנה סביבה:
export OPENAI_API_KEY=sk-your-key-here
```

### התמלול לא מתחיל
1. בדוק את החיבור לאינטרנט
2. וודא שה-URL של השידור תקין
3. בדוק את הלוגים בטרמינל לשגיאות
4. נסה להגדיל את משך הצ'אנק ב"הגדרות מתקדמות"
